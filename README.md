# Space Expedition

## Overview

Space Expedition is a C# console application that helps users manage expedition artifacts and inventory information.

Users can:

- View artifact data
- Search artifacts
- Sort artifact information
- Decode encrypted artifact names
- Add new artifact records
- Save updated data

## Tech Stack

- C#
- .NET
- Console Application
- Visual Studio
- GitHub

## Features

- File handling
- Searching and sorting
- Object-oriented programming
- Inventory management
- Data saving and loading

## Project Structure

- Program.cs
- ArtifactInventory.cs
- Decoder.cs
- Files.cs
- UseMenu.cs

1. Clone the repository

3. Build the solution
4. Run the application
